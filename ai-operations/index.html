HOW WIVIN WORKS

AI가 실행을 돕고,
결정권은 사람에게 남습니다.

01 Conversation

대화가 업무의 출발점이 됩니다.

02 Approval

중요한 실행은 사람이 결정합니다.

권한과 정책을 확인하고 필요한 경우 사람의 승인을 거칩니다.

03 Action

승인된 업무를 실제 실행으로 연결합니다.

04 Memory

결과와 맥락을 조직의 기억으로 남깁니다.

Built today 현재 제품 기반

Conversation workspace

팀 대화와 파일이 같은 업무 맥락 안에서 이어지는 Windows 업무 메신저 기반.

My Space & Files

개인 업무 자료와 파일을 보관하고 다시 찾을 수 있는 개인 작업 공간과 파일 흐름.

Human Approval + Calendar Action

중요한 실행 전에 사람의 승인을 두고, 대화에서 일정 Action으로 연결하는 흐름.

Memory foundation

중요한 맥락과 실행 결과를 다시 활용할 수 있도록 연결하는 Memory 기반.

Organization / permission foundation

조직과 멤버의 역할·접근 범위를 구분하기 위한 권한 기반.

What this enables next 같은 승인·권한 구조 위의 확장 방향

구매 요청

대화에서 요청이 시작되고, 확인과 승인 이후 후속 업무로 이어지는 방향.

업무 보고

대화와 업무 맥락을 필요한 보고 정보와 조직의 확인 절차로 연결하는 방향.

온보딩

기존 조직의 자료와 업무 맥락을 다음 구성원의 업무 시작점으로 연결하는 방향.

기타 반복 조직 업무

같은 승인·권한·실행 구조를 반복적인 조직 업무로 확장하는 방향.

오른쪽 항목은 현재 제공 기능이 아닙니다. WIVIN의 기존 Conversation → Approval → Action → Memory 구조가 확장할 수 있는 제품 방향입니다.
